# Java 11 - Estado do Objeto

## Objetivo

Entender o que define o estado de um objeto (seus atributos), o que define seu comportamento
(seus metodos), como usar `Random` para gerar valores automaticos, e como funciona o ciclo
de vida de um objeto ate o Garbage Collector (GC) da JVM.

## Arquivos

- `Aluno.java` - classe com `Random` para gerar `codigoIdentificador` unico.
- `Principal.java` - demonstra estado inicial, mudanca de estado, GC.
- `Questoes_Java_11_Estado_Objeto.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_11_Estado_Objeto\Aluno.java Java_11_Estado_Objeto\Principal.java
java Java_11_Estado_Objeto.Principal
```
