# Java 09 - Encapsulamento

## Objetivo

Entender o que e encapsulamento, a diferenca entre public e private, e como usar getters e setters para proteger e validar dados.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_09_Encapsulamento.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_09_Encapsulamento\Aluno.java Java_09_Encapsulamento\Principal.java
java Java_09_Encapsulamento.Principal
```
