# Java 04 - Objeto vazio e valores padrao

## Objetivo

Entender que ao nascer um objeto tem valores padrao nos atributos: String recebe null e int recebe 0.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_04_Vazio.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_04_Vazio\Aluno.java Java_04_Vazio\Principal.java
java Java_04_Vazio.Principal
```
