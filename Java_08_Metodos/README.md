# Java 08 - Metodos

## Objetivo

Entender o que e um metodo, a diferenca entre void e com retorno, como usar parametros e por que metodos adicionam comportamento aos objetos.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_08_Metodos.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_08_Metodos\Aluno.java Java_08_Metodos\Principal.java
java Java_08_Metodos.Principal
```
