## Atividade 2 - Perguntas

### Respostas:

* **Em aluno.nome = "Joao Silva";, o que significa aluno.nome?**
R. Significa que estamos acessando especificamente a variável/atributo nome que pertence à instância contida na variável aluno. O código indica o caminho: "vá até o objeto aluno e selecione o campo nome dele".
* **O que acontece se você criar o objeto com new Aluno() mas não preencher nome e idade?**
R. O objeto será criado normalmente na memória, mas seus atributos assumirão os valores padrão automáticos do Java. O atributo nome (que é um objeto do tipo String) começará valendo **null**, e o atributo idade (que é um tipo primitivo numérico) começará valendo **0**.
* **O que o operador . (ponto) permite fazer quando temos um objeto em uma variável?**
R. O operador ponto funciona como uma chave de acesso. Ele permite **navegar para dentro do objeto** para ler (imprimir) ou escrever (modificar/preencher) seus atributos públicos, além de permitir a chamada de seus métodos (comportamentos), caso existam.
