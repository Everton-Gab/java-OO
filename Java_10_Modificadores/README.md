# Java 10 - Modificadores de Acesso

## Objetivo

Entender os modificadores de acesso (`public`, `private`, `protected` e package-private),
como eles controlam a visibilidade de atributos e metodos, e como combina-los corretamente
na declaracao de uma classe.

## Arquivos

- `Aluno.java` - classe com atributos e metodos em diferentes niveis de visibilidade.
- `Principal.java` - arquivo para executar e observar o acesso a cada modificador.
- `Questoes_Java_10_Modificadores.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_10_Modificadores\Aluno.java Java_10_Modificadores\Principal.java
java Java_10_Modificadores.Principal
```
