# Java 06 - Ler atributos

## Objetivo

Praticar a leitura de atributos de um objeto e entender a diferenca entre preencher e ler.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_06_Ler_Atributos.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_06_Ler_Atributos\Aluno.java Java_06_Ler_Atributos\Principal.java
java Java_06_Ler_Atributos.Principal
```
