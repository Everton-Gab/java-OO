# Java 01 - Classe (o molde)

## Objetivo

Entender o que e uma classe em Java, a relacao entre nome do arquivo, nome da classe e ponto de entrada do programa.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_01_Classe.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_01_Classe\Aluno.java Java_01_Classe\Principal.java Java_01_Classe\Professor.java
java Java_01_Classe.Principal
```
