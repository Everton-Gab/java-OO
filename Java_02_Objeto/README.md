# Java 02 - Objeto (instancia)

## Objetivo

Entender o que e um objeto e o papel da palavra `new` na criacao de uma instancia.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_02_Objeto.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_02_Objeto\Aluno.java Java_02_Objeto\Principal.java
java Java_02_Objeto.Principal
```
