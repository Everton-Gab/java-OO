# Java 07 - Construtores

## Objetivo

Entender o que e um construtor em Java e como ele inicializa automaticamente os atributos de um objeto no momento da criacao.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_07_Construtores.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_07_Construtores\Aluno.java Java_07_Construtores\Principal.java
java Java_07_Construtores.Principal
```
