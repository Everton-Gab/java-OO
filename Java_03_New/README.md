# Java 03 - A palavra new e multiplos objetos

## Objetivo

Perceber que `new` e o que cria o objeto na memoria e que e possivel criar varios objetos do mesmo tipo independentes entre si.

## Arquivos

- `Aluno.java` - classe principal do exercicio.
- `Principal.java` - arquivo para executar.
- `Questoes_Java_03_New.md` - enunciado e espaco para suas respostas.

## Como executar (Windows)

```bat
javac Java_03_New\Aluno.java Java_03_New\Principal.java
java Java_03_New.Principal
```
